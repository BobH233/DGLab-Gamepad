# 触控面板

触控面板可从 A/B 通道卡片的指纹按钮打开，也可按默认绑定的 Y 键开关当前选中通道。弹窗通道由来源决定，不提供额外的通道切换。触控模式只接管该通道，另一路继续按原启停状态输出。被接管通道只有在触控区域存在有效触点时才产生输出；抬手、取消触摸、进入设置、退出弹窗、全部停止、离开控制台或应用进入后台都会立即将被接管通道清零。

线性扳机与一键开火在触控模式下仍然生效，并叠加到当前触控输出。触点位于横向中间区域时，基础强度 90 加开火 30 输出 120；线性扳机按行程产生的临时增减同样先计入峰值，再由横向渐变缩放。

## 手柄输入

绑定到「摇杆移动光标」的左右任一方摇杆，在触控面板打开时会作为二维指针控制当前触点。摇杆向量的方向和幅度映射到触控区域，斜向满行程可到达角落；中心死区内发送释放状态，不再产生输出。摇杆移动与手指滑动共用同一套粒子轨迹。屏幕手指输入优先于摇杆，手指抬起后摇杆在下一个 `20Hz` tick 接管。界面用发光实心圆表示触点按下，空心圆保留最后落点。

## 二维映射

- 横向强度在左侧区域从零渐变到峰值，中间区域保持峰值，右侧区域渐变回零；两个分隔手柄可拖动，改变三块区域的宽度。
- 横向峰值取当前通道的计算强度，即基础强度加上仍处于激活状态的线性扳机、一键开火等临时增减；最终再限幅到 `0–200`。
- 纵向波形周期为 `100ms → 10ms → 10ms → 100ms` 的三段映射，对应约 `10Hz → 100Hz → 10Hz`；两个分隔手柄可拖动，改变三块区域的高度。
- V3 波形频率字节按官方压缩公式转换到 `10–240`。
- 触控波形脉宽固定为 `100`，实际输出强度由横向映射决定。

## 高低频平衡

设置中的 `1–15` 值映射到 V3 `BF` 指令的频率平衡参数 `0–255`。A/B 通道各自保存该值；波形脉宽平衡参数固定写 `0`，不会修改用户未设置的脉宽平衡。软上限字节使用 `201`，按协议保持设备已有软上限不变。

## 输出与安全

- `ControlState` 保存目标通道、当前触点和设置，并生成带 `frequencyMs`、`waveformIntensity` 与 `balance` 的动态输出帧。
- `CoyotePacketEncoder` 将动态字段编码为每 `100ms` 一包的 20 字节 B0 数据。
- `CoyoteController` 在强度变化后等待同序列 B1 回应，超过 `700ms` 才解除等待；急停会绕过等待并优先发送零强度空白波形。
- 粒子轨迹与调试读数只在触控组件内部刷新，连续滑动不会重建整个控制台。
- 设置页显示时触控区域被禁用，摇杆脚本和手指输入都不能在后台重新激活该通道。

## 通道控制参数

A/B 卡片上的「临时 +N」标签打开对应通道的模态设置。每路可独立设置线性扳机满行程增量、固定数值/基础强度百分比、以及一键开火增量。按键绑定中的线性强度与一键开火只需选择目标通道和触发方式，运行参数统一读取该通道设置。

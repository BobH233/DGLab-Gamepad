# 冰原狼 2 实机验证

已核实：照片为 Flydigi Direwolf 2；Mac 蓝牙显示 Xbox Wireless Controller，VID 045E / PID 02E0；Apple GameController 返回 Xbox One、extendedGamepad 可用。该身份来自当前兼容模式，不是微软硬件认证结论。

## 按键步骤

保持应用在前台。每个动作结束后松开，间隔约一秒。

1. A、B、X、Y 各按一次；核对南、东、西、北位置。
2. 方向键上、右、下、左，随后按两个斜向组合。
3. 左摇杆分别向四个方向推到边缘，再转一圈并松开；右摇杆重复。
4. LT 与 RT 分别缓慢从松开压到尽头，再同时压下；观察独立的 0..100% 变化。
5. LB / RB、按下左右摇杆 L3 / R3、SELECT / START。
6. 分别按 M1 / M2，观察是否出现已有按键事件。若只出现 A 等标准键，说明当前模式是固件映射，不能标记为独立背键。
7. 可选测试 Home；系统可能截获，不以没有应用事件认定蓝牙失败。
8. 持续按住扳机或按钮超过三秒，确认状态保持。
9. 暂停后按键，确认有效图形清零；继续时先松开全部输入，再重新操作。
10. 关闭手柄，确认设备断开、输入归零；重新连接后从列表选择，不自动接管别的手柄。

展开“输入记录”可看原始变化；右上角复制 JSON。记录保留最近 80 次变化，摇杆连续运动会较快覆盖早先条目；建议分组测试后复制保存。

## 用户实测反馈

2026-10-28，用户自行测试后反馈“没问题了，都可以用了”。下表保留尚未独立采集的逐项证据状态，尤其不据此推断 M1/M2 独立上报或移动端已兼容。用户另反馈 SELECT 连按会触发 macOS 系统录屏；该行为不由原型发起。
